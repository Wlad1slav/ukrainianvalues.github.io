# Ukranianvalues

[Політичний квіз про 🇺🇦 Україну](https://wlad1slav.github.io/ukrainianvalues.github.io/) створений за мотивами проєкту [8values](https://8values.github.io/).

Цей квіз не є політичною агітацією. Питання були сформульовані аматорами, тому результати, які ви отримаєте, не слід сприймати як серйозну аналітику. Основна мета цього тесту — розважити вас. Результати мають жартівливий характер і не претендують на об’єктивність.
